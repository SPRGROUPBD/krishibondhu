# কৃষি বন্ধু (Krishi Bondhu) — ওয়েবসাইট সংস্করণ

সারা বাংলাদেশের (৮ বিভাগ, ৬৪ জেলা) কৃষক ও ক্রেতার জন্য দালালমুক্ত সরাসরি কৃষিপণ্য বাজারের অফিসিয়াল ওয়েবসাইট। এটি অ্যান্ড্রয়েড অ্যাপের সাথে একই **Firebase Realtime Database** (`https://screen-playbd-default-rtdb.europe-west1.firebasedatabase.app`) শেয়ার করে।

## বৈশিষ্ট্যসমূহ
- **রিয়েল-টাইম Firebase সিঙ্ক**: ওয়েবসাইট বা অ্যান্ড্রয়েড অ্যাপ—যেখান থেকেই পণ্য যুক্ত বা অর্ডার করা হোক, তাৎক্ষণিক দুই প্ল্যাটফর্মেই আপডেট হয়।
- **তাৎক্ষণিক অর্ডার নোটিফিকেশন**: ক্রেতা অর্ডার করার সাথে সাথে সংশ্লিষ্ট কৃষকের ড্যাশবোর্ড ও অ্যান্ড্রয়েড ফোনে লাইভ অর্ডার নোটিফিকেশন পৌঁছায়।
- **সুপার অ্যাডমিন নোটিফিকেশন**: অ্যাডমিন (`admin` / `bondhu`) সকল ব্যবহারকারী, শুধুমাত্র কৃষক, শুধুমাত্র ক্রেতা অথবা নির্দিষ্ট কোনো ব্যবহারকারীকে সরাসরি নোটিফিকেশন পাঠাতে পারেন (কোনো ডেমো ডেটা ছাড়া ও অফলাইনেও লগইনযোগ্য)।
- **সারা বাংলাদেশ কভারেজ**: ৮টি বিভাগ ও ৬৪টি জেলা এবং প্রধান উপজেলা অনুযায়ী ফিল্টারিং ও নিবন্ধন।

## লোকাল প্রিভিউ
```bash
python3 -m http.server 8080 -d website
# অথবা
npx serve website
```

## Firebase Hosting-এ ডিপ্লয়মেন্ট
```bash
cd website
firebase login
firebase use screen-playbd
firebase deploy --only hosting
```
